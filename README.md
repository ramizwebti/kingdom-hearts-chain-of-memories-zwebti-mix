# Kingdom Hearts Chain of Memories: Zwebti Mix

A Windows controller action mod built on [ReKHCoM](https://github.com/MatyMeatBoy/ReKHCoM). Requires your own supported USA game dump.

![Kingdom Hearts Chain of Memories: Zwebti Mix](mod/action-edition/branding/kingdom-hearts-chain-of-memories-zwebti-mix-logo.png)

Three normal attacks branch into complete native finishers through direction, hold timing and the selected magic element. There is no finisher menu. A contact-earned assist gauge calls one of14 native allies while Sora keeps fighting. His original portrait, HP, MP and assist gauge sit at bottom right.

- **Play:** [download the Windows launcher from the latest release](https://github.com/ramizwebti/kingdom-hearts-chain-of-memories-zwebti-mix/releases/latest), then choose Story or Practice Arena.
- **Controller tree:** see [the combat guide](mod/action-edition/README.md) or open the interactive `START_HERE.html` included with the release.
- **Native inventory:** see [catalog scope and coverage](mod/action-edition/development/NATIVE_CATALOG.md).
- **Build:** see [launcher/README.md](launcher/README.md).
- **Validation:** see [launcher/VALIDATION.md](launcher/VALIDATION.md).
- **Combat research:** see [the source audit and improvement plan](mod/action-edition/development/COMBAT_RESEARCH.md), covering 20 developer/official references and the principles behind the 0.11.1 candidate.

Version **0.11.1** fixes guide/catalog punctuation while retaining the tested 0.11.0 combat. The combat update adds native recovery links, deliberate opening variations, bounded defense/input buffering, retained targets, safe physical-assist overlap, weighted contact feedback and complete hurt/low-HP portraits. The original multi-hit choreography and supplied silver/gold/pink project branding remain. [Download 0.11.1](https://github.com/ramizwebti/kingdom-hearts-chain-of-memories-zwebti-mix/releases/tag/v0.11.1).

The exact packaged runtime passes 102 combat scenarios, 124 native dispatcher checks, 14 strict flow cases, 11 assist probes and the documented visual/HUD checks. Physical controller feel, full campaign progression and encounter-wide balance remain unverified. Story/Practice profiles stay outside immutable version folders. Hosted Windows checks and packaging keep new helper EXEs off the developer's computer.

Independent fan modification. No ROM, saves or player data are included. Original source and third-party notices retain their terms.
